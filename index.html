RSBSA farmer registry database

Import farmer-level records, filter by location or crop, and see verification coverage at a glance.

Records are stored in this browser's IndexedDB, tied to this file — they'll persist next time you reopen it in the same browser on this computer, but won't follow you elsewhere. Use Export CSV to back up or move data.

Import records

Paste directly from Excel (select your header row + data, copy, paste below), or upload a CSV file. Expected columns: rsbsa_no, control_no, first_name, middle_name, last_name, ext_name, farmer_address_bgy, farmer_address_mun, farmer_address_prv, birthday, gender, contact_num, cropname, crop_area, verified_area(for_testing), farmer, farmworker, fisherfolk, agency, farm_type, date_created, kyc_updated, parcel_updated — in any order, as long as the header row is included.
